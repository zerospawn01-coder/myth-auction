# 次に作るべきものは、一般的な企画書や大量のエピソードではなく、**「接続による自由」が本当にゲームとして成立するかを証明する最小プロトタイプ仕様**です。

# 次の制作物

## MYTH AUCTION「対象研究スライス v0.1」

一つの呪物を中心に、研究・取引・公開・保管という異なる活動が、同じデータと操作体系から分岐する縦断スライスを作ります。

### 最小構成

| 要素     |     数 |
| ------ | ----: |
| 固有対象   |    1点 |
| 関係者    | 3人／存在 |
| 道具     |    3種 |
| 基本行為   |    6種 |
| 実験条件   |    4種 |
| 永続的な結果 |   3系統 |
| 後日変化   |  2〜3件 |

## 研究対象

例として、**「所有者の夢の中で泣く陶製人形」**を使います。

初期情報：

```text
確認済み
・夜間のみ声を発する
・所有者から離しても夢への干渉が続く

未解明
・声の発生源
・人形内部の構造
・元所有者との関係
・売却後も作用が残るか
```

## 接続できる人脈

* 呪物専門ブローカー：市場価値、過去の所有者、買い手を調査
* 音響研究者：声の記録、周波数解析、再現実験
* 人外の夢仲介者：夢への侵入、対象との対話、異界への返却

誰と接続するかによって、単に結果文が変わるのではなく、**利用できる工程そのもの**が変化します。

# 操作文法

プレイヤーは文章を入力せず、次を組み合わせます。

```text
対象
× 行為
× 道具
× 協力者
× 条件
```

例：

```text
泣く人形
× 観測する
× 指向性マイク
× 音響研究者
× 所有者が睡眠中
```

別の構成：

```text
泣く人形
× 接触する
× 夢記録器
× 夢仲介者
× 元所有者の名前を呼ぶ
```

同じ対象でも、構成した工程によって異なる証拠、危険、関係変化が発生します。

# 6つの基本行為

最初は次だけで十分です。

```text
観測する
照会する
実験する
保管する
公開する
譲渡する
```

自由度は動詞の数ではなく、**対象・道具・人物・条件との組み合わせ**から作ります。

# UI構成

施設マップは使わず、対象中心のワークベンチUIにします。

```text
┌─────────────────────────┐
│ 対象：泣く陶製人形       │
│ 確認済み性質 / 未解明点  │
├──────────┬──────────────┤
│ 道具      │ 接続可能な人脈 │
│ マイク    │ 音響研究者     │
│ 低温容器  │ ブローカー     │
│ 夢記録器  │ 夢仲介者       │
├──────────┴──────────────┤
│ 構成中の工程             │
│ 観測 × マイク × 研究者   │
├─────────────────────────┤
│ 実行 / 記録 / 中止        │
└─────────────────────────┘
```

人脈ネットワークは別画面の巨大な相関図にせず、**現在の対象に対して何を可能にする人物か**として表示します。

# 永続化するもの

結果文だけではなく、最低限以下を保存します。

```text
何を対象にしたか
誰を関与させたか
何を使用したか
どの条件で実行したか
何を観測したか
どの主張が支持・反証されたか
誰との関係が変化したか
対象に何が残ったか
```

これが、論文、売却説明、後日の事件、第三者による再実験の根拠になります。

# 成功条件

このプロトタイプが合格する条件は、画面が美しいことではありません。

1. 同じ呪物を30分以上研究し続けても、新しい判断が発生する
2. 売却しなくても研究プレイが成立する
3. 人脈を一つ拒絶しても、別の方法で同じ目的へ接近できる
4. プレイヤーが用意された物語を選ぶのではなく、自分の研究履歴を説明できる
5. 結果が数値だけでなく、対象・人脈・利用可能な操作に残る

この5点を満たした後に、出品物や客を増やします。

したがって次の優先順位は、

```text
1. 対象・人脈・行為・履歴のデータモデル
2. 一つの呪物を扱うワークベンチUI
3. 行為合成と実行判定
4. 論文・取引・後日談への履歴再利用
5. 対象と人脈の追加
```

です。

**次に証明すべきなのは「何でも用意できること」ではなく、「一つの対象から、プレイヤー自身の目的が自然に生まれること」です。**
