# M4.7 Economy Balance Baseline Report

## 実行条件

- Godot: 4.7 stable
- 戦略: `safe` / `balanced` / `risky`
- 試行: 各戦略100シード
- 期間: 1シードあたり100日（2,400時間）
- チェックポイント: Day 1 / 10 / 100
- 総記録数: 900行（3戦略 × 3時点 × 100シード）
- シード重複・欠落: なし

直列実行は720,000回の状態更新で10分を超えたため、10シード単位の10ワーカーへ分割した。同じシード式とゲームロジックを使い、CSVを完了後に統合した。

## 結論

現行設定では、報酬量を比較できる持続的な経済ループが成立していない。全戦略がDay 1中に利用可能電力を使い切り、その後は新しい任務を開始できない。結果として、全指標がDay 1からDay 100まで完全に変化しない。

`current_power`は初期化時に一度だけ計算され、任務tickごとに消費される。日跨ぎの回復処理はなく、現在のコンソールUIにも`set_current_power()`を実行する操作がない。このため、これはシミュレーター固有の停止ではなく、通常プレイでも到達し得る電力デッドロックである。

## 判定軸の評価

### 1. 初回合成アクセス

全戦略・全シードでDay 1にScout合成へ到達した。初期資源はDust 45 / Cells 15、ScoutコストはDust 20 / Cells 5であり、探索前から購入可能である。

目標が「Day 10までに50%以上」だけなら達成しているが、「早すぎず遅すぎない」という意図には合致しない。初回合成を成長目標にする場合、開始時点で100%購入可能な現状は再検討が必要。

### 2. 資源飽和

判定不能。資源が飽和しないのは消費と報酬が釣り合っているためではなく、Day 1以降に任務が停止するためである。

### 3. リスクプレミアム

成立していない。

- riskyはCellsとDataでsafeを上回る。
- Dustではbalancedが最大で、riskyはsafeとほぼ同等。
- riskyは成功率66.67%だが、期待総報酬が明確に優位とはいえない。
- balancedはsafeと同数の成功を得る一方、約7.8倍のDamageを受け、Dust差は約3.4に留まる。

ただし試行がDay 1で打ち切られるため、長期的なリスクと修復費用を含む最終判断はできない。

## 修正優先順位

1. 電力回復ループを仕様化する。
   - 日次でグリッド利用可能量まで回復する。
   - プレイヤー操作で発電・再配分する。
   - 資源消費で充電する。
   - 上記のいずれを採用するか決定し、UIと自動シミュレーターへ同じ操作を実装する。
2. 電力修正後、同一100シードでベースラインを再実行する。
3. 初回合成を成長目標にする場合、初期資源またはScoutコストを調整する。
4. 持続的な任務数が得られてから報酬幅、損傷、修復費用、リスクプレミアムを調整する。

報酬値を先に変更すると、電力停止による歪みを報酬量で補正してしまうため推奨しない。
